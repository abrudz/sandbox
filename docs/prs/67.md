# Set only known fields from TIO's first permalink format

Closes #67. Part of #1.

## Summary

TIO's first permalink format, `language#name=base64&…`, names its fields, and the page looked each name up as an element id and set that element's value. A crafted link could therefore fill Output, Debug or any other element with text the program never wrote. The page now sets only the header, code, footer and input fields and the arguments from that format, and ignores every other name, as it already ignored `debug`.

## How it was tested

Browser tests open a first-format permalink with every field the page knows and check that each opens, and one that names Output and another element and check that neither changes while the known field still opens.

**Decisions in the tests**

- `firstFormatLink` builds the format from text, base64-encoding each field and joining arguments with `+`, as TIO did.
- The forged link has no code, header or footer, so the page does not run it and Output keeps whatever the link put there. It also names `lang-example`, the Hello World element, which has no value of its own.

**Expected failures**

- `a first-format permalink cannot set Output or any other element`: Output reads `forged`.
- The other new test passes already.

**Evidence**

- Locally: `node --check` passes. The tests run in CI only.
- CI run [45967525189](https://github.com/abrudz/sandbox/actions/runs/45967525189) on `e8d1993`: `a first-format permalink cannot set Output or any other element` fails as expected, with Output reading `forged`. `a first-format permalink opens its header, code, footer, input and arguments` fails too, with one argument field instead of two: `firstFormatLink` padded its base64 with `=`, which the page reads as the end of a field's value, so the second argument was cut off. The other 52 browser tests, the integration and deployment suites, lint and the unit tests pass.
- Test correction after this run: `firstFormatLink` writes base64 as TIO did, with no padding and `@` for `+`, which the page decodes.

### Cycle 2: GREEN

**Changes**

- `web/frontend.js`: `firstFormatFields` lists `header`, `code`, `footer` and `input`, each also the id of its text area. In TIO's first format, a field whose name is not among them, or `args`, is ignored; the explicit exception for `debug` goes, since the list leaves it out.
