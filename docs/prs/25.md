# Make the language bar's border transparent and drop its wrapper

Closes #25.

## Summary

The language bar's bottom border is transparent, so the bar's background shows through it. lb.js appends the bar itself to the body, without the `div` it wrapped the bar in.

## How it was tested

Playwright tests in CI against the container, and locally against the preview server. The change was made without separate review stops, at the reviewer's request.

## Cycles

### Cycle 1: RED and GREEN

**Test surface**

| Test | Change |
|---|---|
| `the language bar is a child of the body` | New |
| `the language bar's bottom border is transparent` | New |

**Changes**

- `web/frontend.css`: `.ngn_lb`'s bottom border is `solid transparent 1px`. Its width is unchanged, so the bar keeps its height.
- `web/lb.js`: the bar is created as the `div.ngn_lb` itself and appended to the body. The bar's variable is now that element, not the wrapper's first child. The header comment and `THIRD_PARTY_NOTICES` record the change.

**Evidence**

- Locally, against the preview server:
  - Without the change, both new tests fail. The bar's parent is the wrapper `div`, and its border colour is `rgb(32, 32, 32)`.
  - With the change, all 49 UI tests that need no container pass, as do the codec tests.
