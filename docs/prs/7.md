# Adapt TIO's apl-dyalog frontend to the run API

Closes #7. Work item 6 of [docs/plans/dyalog-runner.md](../plans/dyalog-runner.md).

## Summary

`runner-api` serves `web/` at `/`: TIO's interpreter page (`index.html`, `frontend.js`, `frontend.css`, its fonts and `pako`, MIT) reduced to `apl-dyalog`, with `abrudz/lb` for APL glyph input. The page opens directly on `apl-dyalog`. Run posts JSON to `/api/v1/run`, and clicking Run again aborts the request, which stops the run on the server. Output shows stdout, and Debug shows stderr followed by TIO's timing lines; CR line endings display as line breaks. Permalinks keep TIO's format, so a tio.run `apl-dyalog` link opens here unchanged once its host is replaced. The page shows the interpreter's version and loads nothing from any other origin.

## How it was tested

Node unit tests for the permalink and output helpers (`web/codec.js`) and a Go unit test for serving the frontend run in the dev container. Playwright tests drive Chromium against the container in CI (plan, Development environment); each cycle below links its CI run.

**Decisions in the tests**

- Debug must end with TIO's lines, in TIO's format: `Real time`, `User time` and `Sys. time` in seconds to three decimals, `CPU share` as a percentage to two decimals, and `Exit code`.
- The permalink formats must contain the permalink and no "Try it online" or "tio.run" branding. The Code Golf format starts with `# [APL (Dyalog Unicode)], N bytes`.
- The cancellation test waits until a `dyalog` process exists in the container, clicks Run again, and requires the button to stop spinning and the process to be gone within 2 s each.
- The language bar test types backtick then `r` (`⍴`) and clicks `⍳` in the bar.
- The origin test loads a permalink, runs it and opens the permalink drawer, recording every request the page makes.

**Expected failures**

- The five codec tests: "not implemented".
- `TestGetRootServesTheFrontend`: `GET /` and `GET /frontend.js` answer 404.
- All ten Playwright tests: `/` answers 404, so the page's elements never appear and every test times out waiting for them.

**Evidence**

- Locally: `node --test test/ui/codec.test.js` fails all five tests with "not implemented"; `go test ./...` fails `TestGetRootServesTheFrontend` with 404; `npx playwright test --list` lists the ten browser tests.
- CI run [44511847161](https://github.com/abrudz/sandbox/actions/runs/44511847161) on `432f6cb`: lint passes, the image builds, and all 42 integration tests pass. `TestGetRootServesTheFrontend` fails with 404, and all ten Playwright tests fail waiting for elements of a page that is not served. The Go unit-test failure stopped the `checks` job before the codec tests, so the frontend steps now run whatever the earlier steps did; the next run shows the codec failures as well.

**Anticipated implementation order**

1. `web/codec.js`: TIO's byte-string, base64 and raw-deflate helpers moved out of `frontend.js` unchanged, plus `fieldsToPermalink`, `parsePermalink` and `displayText`.
2. `internal/api`: serve `WebDir` at `/`; `cmd/runner-api` points it at `/usr/share/sandbox/web`, and the image copies `web/` there.
3. `web/index.html`, `frontend.css`, `frontend.js` from TIO:
   - **Page:** drop the home drawer, language list, search, "switch languages", sponsors and donation links; replace the branding with `dyalog.run`, including in the permalink formats; fix the `${tio_*}` paths; add `lb.js` and a version label.
   - **Running:** Run uses `fetch` and an `AbortController` against `/api/v1/run`, and fills Output and Debug from the JSON. Debug gets TIO's timing lines and its wording for truncation and timeouts.
   - **Permalinks:** saving and loading go through the codec, and an empty fragment opens `apl-dyalog`.
   - **Removed code:** the cache probe, GitHub sign-in and random-token code.
4. `web/lb.js` and its font as published by `abrudz/lb`, with the CSS changes the page layout needs.
5. `THIRD_PARTY_NOTICES`: TIO's frontend, pako, `lb` and the fonts.
