# Adapt TIO's apl-dyalog frontend to the run API

Closes #7. Work item 6 of [docs/plans/dyalog-runner.md](../plans/dyalog-runner.md).

## Summary

`runner-api` serves `web/` at `/`: TIO's interpreter page (`index.html`, `frontend.js`, `frontend.css`, its fonts and `pako`, MIT) reduced to `apl-dyalog`, with `abrudz/lb` for APL glyph input. The page opens directly on `apl-dyalog`. Run posts JSON to `/api/v1/run`, and clicking Run again aborts the request, which stops the run on the server. Output shows stdout, and Debug shows stderr followed by TIO's timing lines; CR line endings display as line breaks. Permalinks keep TIO's format, so a tio.run `apl-dyalog` link opens here unchanged once its host is replaced. The page shows the interpreter's version and loads nothing from any other origin.

## How it was tested

Node unit tests for the permalink and output helpers (`web/codec.js`) and a Go unit test for serving the frontend run in the dev container. Playwright tests drive Chromium against the container in CI (plan, Development environment); each cycle below links its CI run.

**Decisions in the tests**

- Debug must end with TIO's lines, in TIO's format: `Real time`, `User time` and `Sys. time` in seconds to three decimals, `CPU share` as a percentage to two decimals, and `Exit code`.
- The permalink formats must contain the permalink and no "Try it online" or "tio.run" branding. The Code Golf format starts with `# [APL (Dyalog Unicode)], N bytes`.
- The cancellation test waits until a `dyalog` process exists in the container, clicks Run again, and requires the button to stop spinning and the process to be gone within 2 s each.
- The language bar test types backtick then `r` (`⍴`) and clicks `⍳` in the bar.
- The origin test loads a permalink, runs it and opens the permalink drawer, recording every request the page makes.

### Cycle 2: GREEN

**Changes**

- `web/codec.js`:
  - **TIO's helpers.** The byte-string, base64 and raw-deflate helpers are moved out of TIO's `frontend.js` unchanged.
  - **`fieldsToPermalink`** joins language, header, code, footer, input and arguments with `\xff` and encodes them as TIO did.
  - **`parsePermalink`** reads a bare language or TIO's `language#state` and `#state` forms. It ignores TIO's extra fields and settings, which `apl-dyalog` permalinks never carry.
  - **`displayText`** turns CR and CRLF into line feeds.
- `web/index.html`, from TIO's:
  - **Removed:** the home drawer, the language list and search, "switch languages", the settings and the option, compiler-flag and driver fields.
  - **Navigation:** the TIO logo becomes a `dyalog.run` link, which opens a new program.
  - **Version:** a version label sits beside the language name.
  - **Permalink formats:** they say "Try it on dyalog.run!".
  - **Scripts and icon:** scripts load from `/`, `lb.js` before `frontend.js` so the language bar exists when the page lays out. An empty `data:` icon keeps the browser from requesting `/favicon.ico`.
- `web/frontend.js`, from TIO's:
  - **Run.** Run posts `{code, input, args}` to `/api/v1/run` through `fetch` with an `AbortController`. Code is header, code and footer joined with line feeds, as TIO joined them. A second click aborts the request. A non-200 answer shows its status and body as a message; a network failure shows TIO's connection message.
  - **Output and Debug.** Output is stdout through `displayText`. Debug is stderr through `displayText`, followed by TIO's lines: real, user and system time to three decimals, CPU share to two, and the exit code. A signal is reported as 128 plus its number, as bash reported it to TIO. Truncation and timeouts raise TIO's warnings.
  - **Permalinks.** Saving and loading go through the codec, and TIO's oldest `field=value` format still loads. An empty fragment, and tio.run's `home`, `community` and `get-started` fragments, open `apl-dyalog`. Any other language shows TIO's "language not found" message.
  - **Language bar.** The bar sits under the navigation bar and the page under both. A `ResizeObserver` follows the bar's height as its font loads, the window narrows or the bar is closed.
  - **Glyph insertion.** `lb.js` inserts glyphs without an input event, so the byte count and field size refresh on key-up and mouse-up. When `lb.js` completes a two-character sequence on Tab, the page does not also insert a tab.
  - **Removed:** the language list, cache probe, GitHub sign-in, settings, random-token and SHA-256 code.
- `web/frontend.css`, from TIO's:
  - **Fonts and pruning.** Font URLs point at `/`, and rules for removed elements are gone.
  - **Monospace face.** DejaVu Sans Mono is declared as `Sandbox Mono`: `lb.js` declares a `DejaVu Sans Mono` face whose fallback file it does not ship, and that declaration would replace the page's.
  - **Language bar.** It takes the page's colours and font. The body margin `lb.js` sets is overridden, since the layout is fixed.
  - **Add and remove buttons.** `.array-add` and `.array-remove` are inline blocks. `#main`'s `font-size: 0` otherwise leaves the inline spans with no height of their own, which Playwright treats as hidden.
  - **Site name.** The `dyalog.run` link keeps its full 144 px width. TIO limits navigation buttons to 22% of the width, which fits its 64 px logo but clipped the name at phone widths. All three buttons still fit at 320 px.
- Static assets:
  - `web/languages.json` is TIO's `apl-dyalog` entry without its `categories` and `update` keys.
  - `web/lb.js` is `abrudz/lb` at `342eec94`, unmodified.
  - The Exo 2 and DejaVu Sans Mono 2.35 web fonts are TIO's.
- `internal/api`: with `WebDir` set, `GET /` serves its files through `http.FileServer`. The API routes are more specific and take precedence.
- Image and notices:
  - `cmd/runner-api` sets `WebDir` to `/usr/share/sandbox/web`.
  - The image copies `web/` there, and `.dockerignore` admits `web/`.
  - `THIRD_PARTY_NOTICES` lists TIO's frontend, pako, `lb`, Exo 2 and DejaVu Sans Mono, with their licences.

**Test changes in this cycle**

- `each permalink format is generated…` checked the two argument fields with `toHaveValues`, which asserts the selected options of one `<select multiple>`. On two textareas it fails with a strict-mode violation whatever their values. The test now checks the count and each value with `toHaveValue`.

- When stderr is empty, Debug starts with an empty line before the timing lines, as on TIO.
- The page sends no Content-Security-Policy. TIO's inline `onclick` handlers and the `<style>` elements `lb.js` injects would need `'unsafe-inline'`; a policy belongs with the deployment (#9).
