# Keep the favicon still while a run is in progress

Closes #29. Follows #27.

## Summary

The favicon stays the Run button's logo, `favicon.svg`, whose colour follows the browser's theme. Seen in a browser, the animated favicon looked janky. The code that existed only to animate it goes: drawing the favicon as a data URL, the timer that turned it in a hidden tab, and the `visibilitychange` handling. The Run button animates as it did before #27.

## How it was tested

Playwright tests in CI against the container, as for #7, and locally against the preview server.
