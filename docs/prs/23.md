# Refine the frontend for one language and update dependencies

Closes #23. Follows the plan's frontend work ([docs/plans/dyalog-runner.md](../plans/dyalog-runner.md), Frontend), after use of the local instance.

## Summary

The frontend drops what only mattered for TIO's many languages: the language list, the other encodings' byte counts, the language index and the advice to refresh a stale list. Input is sent with a line break added at its end, so that reading its last line does not end in `EOF INTERRUPT`, and a line break the user ends it with answers a prompt with an empty line. lb.js no longer styles the language bar; `frontend.css` does. A button at the right end of the navigation bar opens the APL Wiki, with hotkey W. The heading reads "Dyalog". Text outside the code fields and the language bar uses APL335, and bold text is drawn with a text stroke and letter spacing, since APL335 has one weight. pako, Go, staticcheck, Playwright, Node and the GitHub Actions are updated to their current releases.

## How it was tested

Playwright tests in CI against the container, as for #7, with the APL Wiki answered by the test. A local preview server (`api.NewHandler` serving `web/`, with an executor running the dev container's `dyalogscript`) gives earlier feedback for the tests that need no container. The dependency updates have no tests of their own: the full suite, run with the new versions, is their check.

**Decisions in the tests**

- Language list: no request whose path contains `languages` may be made by the time the page's network is idle. The not-found message must still say that the requested language could not be found, but not mention refreshing or caching.
- Input:
  - The issue's permalink runs on load. Output must be `hi` and Debug must not contain `EOF INTERRUPT`.
  - The run request's `input` must be the field with a line break added: `a\nb\n` for `a\nb`, `a\nb\n\n` for `a\nb\n`, and `\n` for an empty field. A line break the user ends the input with may be meant as an empty answer, so it is not taken to be the final one; an extra empty line at the end does no harm.
  - `⎕←⍞` then `⎕←'[',⍞,']'` with the input `a\n` must show `a` and `[]` in Output, with no `EOF INTERRUPT`.
  - The Input field must keep what the user typed; only the request changes.
- Styles: there must be no `style` elements, and `body` must have no `style` attribute (lb.js set its top margin there).
- Fonts:
  - `document.fonts` must hold only the APL335 and APL387 families. That excludes Exo 2 and lb.js's DejaVu Sans Mono.
  - The heading, version, section headings, Hello World link, argument `+`, and code size must use APL335, and APL335 must load.
- Bold:
  - The section headings, the heading, the argument `+` and a message title must have weight 400, with a non-zero text stroke and letter spacing.
  - The version, plain text inside the heading, must have neither.
  - The tests check that both are present, not their exact width of 0.05ch.
- APL Wiki button:
  - At 1280 by 720 and at 360 by 640:
    - its top, width and height must equal the Run button's;
    - its right edge must be the navigation bar's;
    - it must start to the right of the permalink button.
  - Its logo path must start as `apl/white.svg`'s first path does. Its background, its paths' fill and its logo's height must equal the Run button's, with the pointer away from both.
  - Clicking it, and pressing Escape then W, must open `https://aplwiki.com/` in a new tab, which the test answers itself. The program must stay in the original tab.
- The copy formats keep "Dyalog APL" as the language's name: the permalink formats test still expects `# [Dyalog APL], N bytes`.

### Cycle 2: GREEN

**Changes**

- Dependencies:
  - `web/pako.min.js` is pako 3.0.3's `dist/browser/pako.umd.min.js`, from the npm tarball whose integrity matched the registry's. It has a version comment at its head, and its source map comment is removed, as the map is not shipped. pako 3 inflates byte arrays only, so `codec.js` converts the byte string first. pako 3 compresses differently from pako 1, so a program's permalink has different characters from before; both decode the same, and every existing permalink still opens.
  - `go.mod` says `go 1.27`, which CI's `setup-go` resolves to the latest 1.27 release. The image builds `runner-api` in `golang:1.27-trixie`, the Debian release of the final stage.
  - CI runs staticcheck 2026.2.2, Node 26, and `actions/checkout`, `actions/setup-go` and `actions/setup-node` v7. Their release notes list no change to the inputs these workflows use.
  - `test/ui` uses Playwright 1.65.1, with its lock file.
- `web/frontend.js`:
  - **One language.** `languageId`, `languageName`, `languageLink` and `helloWorld` hold what `languages.json` held. The page boots without fetching anything first.
  - **Permalinks.** `hashToState` returns the permalink's language. `init` shows the interpreter for `apl-dyalog`, and for any other language unchecks it and says the language could not be found.
  - **Saving state.** `saveState` records nothing while the interpreter is hidden.
  - **Byte counts.** `countCharacters` and `countBytes` (UTF-8) replace TIO's per-encoding `countBytes`.
  - **Removed.** `testToState`, the tab character per language, and the xxd pattern go.
  - **Input.** `runRequestBody` adds a line break to the input.
- `web/index.html`:
  - The heading's name ("Dyalog") and link are in the markup.
  - TIO's index section and `#toggle-index` go.
  - The navigation bar ends with `<a id="wiki" href="https://aplwiki.com/" target="_blank" rel="noopener" data-hotkey="W">`. It holds the logo's two paths with their fill removed and their even-odd rule and transform kept. Its 1890 by 1889 clip rectangle becomes the viewBox, and it is shown at 32 by 32.
- `web/lb.js`: its two `style` elements and the body margin it set on load and resize are removed.
- `web/frontend.css`:
  - **Language bar.** The rules for it now come from lb.js, in the page's colours. They need neither raised specificity nor the `!important` body margin.
  - **APL Wiki button.** `#wiki` is pushed to the right with `margin-left: auto`.
  - **Fonts.** APL335 replaces Exo 2 for the body and the argument buttons.
  - **Bold text.** Text that was weight 600 has weight 400, with `-webkit-text-stroke: 0.05ch; letter-spacing: 0.05ch`. That covers the section headings, the argument buttons and message titles. `.prose` resets both.
  - **Heading.** The heading inherits `#main`'s font size of 0, so its emphasis would compute to nothing. The emphasis is set on `#lang-name` and the Hello World link instead.
- Files:
  - `web/APL335.woff2` and `web/APL335.woff` come from release 2026-10-30, whose published digests they match.
  - The Exo 2 files and `web/languages.json` are removed.
- `THIRD_PARTY_NOTICES`:
  - pako 3.0.3, with its zlib licence;
  - Go 1.27;
  - the lb changes;
  - APL335 beside APL387;
  - the APL logo (CC0);
  - Exo 2 and its licence removed.
- The plan: the Go and Node versions, the notices, `web/`'s contents, and the frontend's input, fonts and APL Wiki button.
