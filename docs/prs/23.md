# Refine the frontend for one language and update dependencies

Closes #23. Follows the plan's frontend work ([docs/plans/dyalog-runner.md](../plans/dyalog-runner.md), Frontend), after use of the local instance.

## Summary

The frontend drops what only mattered for TIO's many languages: the language list, the other encodings' byte counts, the language index and the advice to refresh a stale list. Input without a final line break is sent with one, so that reading its last line does not end in `EOF INTERRUPT`. lb.js no longer styles the language bar; `frontend.css` does. A button at the right end of the navigation bar opens the APL Wiki, with hotkey W. The heading reads "Dyalog". Text outside the code fields and the language bar uses APL335, and bold text is drawn with a text stroke and letter spacing, since APL335 has one weight. pako, Go, staticcheck, Playwright, Node and the GitHub Actions are updated to their current releases.

## How it was tested

Playwright tests in CI against the container, as for #7, with the APL Wiki answered by the test. A local preview server (`api.NewHandler` serving `web/`, with an executor running the dev container's `dyalogscript`) gives earlier feedback for the tests that need no container. The dependency updates have no tests of their own: the full suite, run with the new versions, is their check.

**Decisions in the tests**

- Language list: no request whose path contains `languages` may be made by the time the page's network is idle. The not-found message must still say that the requested language could not be found, but not mention refreshing or caching.
- Input:
  - The issue's permalink runs on load. Output must be `hi` and Debug must not contain `EOF INTERRUPT`.
  - The run request's `input` must be `a\nb\n` for the field `a\nb`, `a\nb\n` for `a\nb\n`, and empty for an empty field.
  - The Input field must keep what the user typed; only the request changes.
- Styles: there must be no `style` elements, and `body` must have no `style` attribute (lb.js set its top margin there).
- Fonts:
  - `document.fonts` must hold only the APL335 and APL387 families. That excludes Exo 2 and lb.js's DejaVu Sans Mono.
  - The heading, version, section headings, Hello World link, argument `+`, and code size must use APL335, and APL335 must load.
- Bold:
  - The section headings, the heading, the argument `+` and a message title must have weight 400, with a non-zero text stroke and letter spacing.
  - The version, plain text inside the heading, must have neither.
  - The tests check that both are present, not their exact width of 0.05ch.
- APL Wiki button:
  - At 1280 by 720 and at 360 by 640:
    - its top, width and height must equal the Run button's;
    - its right edge must be the navigation bar's;
    - it must start to the right of the permalink button.
  - Its logo path must start as `apl/white.svg`'s first path does. Its background, its paths' fill and its logo's height must equal the Run button's, with the pointer away from both.
  - Clicking it, and pressing Escape then W, must open `https://aplwiki.com/` in a new tab, which the test answers itself. The program must stay in the original tab.
- The copy formats keep "Dyalog APL" as the language's name: the permalink formats test still expects `# [Dyalog APL], N bytes`.

**Anticipated implementation**

1. Dependencies:
   - `web/pako.min.js` becomes pako 3.0.3's `dist/browser/pako.umd.min.js`. `codec.js` passes a byte array to `inflateRaw`.
   - `go.mod` and the image's build stage move to Go 1.27, and CI to staticcheck 2026.2.2.
   - `test/ui/package.json` moves to Playwright 1.65.1, with its lock file.
   - The workflows move to Node 26 and to `actions/checkout`, `actions/setup-go` and `actions/setup-node` v7.
   - `THIRD_PARTY_NOTICES` follows: pako's version and its Zlib licence, Go 1.27.
2. One language: `languages.json` and its loading go. The page's language is Dyalog's name, link, encoding and Hello World program, set in `index.html` and `frontend.js`. `countBytes` keeps characters and UTF-8. TIO's index section and `#toggle-index` go.
3. Input: `runRequestBody` adds a line break to non-empty input that does not end with one.
4. lb.js: its `style` elements and the body margin it sets go, so the `!important` override and the raised specificity in `frontend.css` go too. `THIRD_PARTY_NOTICES` records the change.
5. APL Wiki button: `<a id="wiki" href="https://aplwiki.com/" target="_blank" rel="noopener" data-hotkey="W">` at the end of the navigation bar, pushed right with `margin-left: auto`. It holds the logo's paths without their white fill, so they take the buttons' fill.
6. The heading's name is "Dyalog".
7. Fonts: `APL335.woff2` and `APL335.woff` from Dyalog/APL387 release 2026-10-30 replace the Exo 2 files. Each `font-weight: 600` becomes `-webkit-text-stroke: 0.05ch; letter-spacing: 0.05ch`, and plain text inside a heading resets both.
